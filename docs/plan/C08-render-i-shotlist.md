# C08 — `tools/render.mjs` + `tools/shotlist.mjs`

**Faza:** 1 (deterministički alati) · **Zavisi od:** C01 (shema), C06 (fixture-i) · **Procena:** ~100k tokena
**Izvorni plan, sekcije:** „render.mjs", „shotlist.mjs".

## Cilj

Dva formatera nad `storyboard.json`. Nema logike, nema odluka — samo prikaz.
Zato ova celina ide brzo i može se raditi paralelno sa C09.

## `tools/render.mjs`

```
node tools/render.mjs episodes/<slug>
```

`storyboard.json` → `storyboard.md`, čitljiv ljudski prikaz.

**`storyboard.md` se nikad ne piše ni menja ručno.** Fajl mora da počne linijom:

```
<!-- GENERATED by tools/render.mjs — DO NOT EDIT. Source of truth: storyboard.json -->
```

Sadržaj po beatu: id · vremenski opseg · trajanje · uređaj · `NARRATION SAYS` / `VIEWER SEES` ·
lista shotova sa `use_in–use_out`, `use_len`, tagovima i oba prompta.

**Mora biti deterministički** — dva pokretanja nad istim `storyboard.json` daju bajt-identičan fajl.
To znači: nema `new Date()` u telu (osim ako se čita `generated_at` iz JSON-a), nema iteracije po
neuređenom objektu.

## `tools/shotlist.mjs`

```
node tools/shotlist.mjs episodes/<slug> [--only 07,12,18]
```

Produkciona čeklista za Flow, **u redosledu generisanja**. Po shotu:

- broj shota
- image prompt — u bloku spremnom za copy, bez markdown ukrasa unutra
- animation prompt — isto
- koja slika ide kao *ingredient*
- podsetnik: `sačuvaj generisanu sliku kao images/shotNN.jpeg`

**Linked shotovi (A/B/C istog beata) grupisani zajedno**, sa naznakom da dele lokaciju i svetlo.

`--only` postoji jer Flow nije deterministički — odbacićeš i regenerisati pojedinačne shotove.
Tada ti treba samo tih par promptova, ne cela lista od 30.

## Isporučuje

- `tools/render.mjs`
- `tools/shotlist.mjs`
- `tests/render.test.mjs` (determinizam + prisustvo DO-NOT-EDIT zaglavlja)
- `tests/shotlist.test.mjs` (`--only` filtriranje, grupisanje linked shotova)

## Verifikacija — definicija gotovog

```bash
node tools/render.mjs tests/fixtures/good-episode
cp tests/fixtures/good-episode/storyboard.md /tmp/a.md
node tools/render.mjs tests/fixtures/good-episode
diff /tmp/a.md tests/fixtures/good-episode/storyboard.md    # prazno → deterministički

node tools/shotlist.mjs tests/fixtures/good-episode --only 1,3   # tačno 2 stavke
node tools/shotlist.mjs tests/fixtures/good-episode | head -40   # linked shotovi grupisani
node --test tests/
```

Plus ručno: pročitaj `storyboard.md` i potvrdi da je **upotrebljiv bez otvaranja JSON-a**.
To je jedini kriterijum koji stvarno meri da li render radi svoj posao.

## Zamke

- Ne dodavati u `storyboard.md` ništa čega nema u `storyboard.json`. Prvi put kad `.md` ponese
  informaciju koje nema u izvoru, dva prikaza se razilaze i `render.mjs` postaje beskoristan.
- Prompt blokovi u `shotlist` izlazu ne smeju biti prelomljeni — kopiraju se direktno u Flow.

## Tačka preseka ako sesija pređe budžet

`render.mjs` i `shotlist.mjs` ne dele kod. Preseci između njih.
